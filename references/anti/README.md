# O que a More não é

A IA lê esta lista antes de criar. Se a peça parece com algo daqui, volta.

- **Render decorado**: ambiente de apartamento-modelo, tudo novo, tudo no lugar, ninguém mora ali.
- **Moodboard bege genérico**: o mesmo linho, a mesma cerâmica, o mesmo vaso, em qualquer marca. É a média.
- **Ambiente gerado por IA**: luz sem fonte, sombra sem janela, peça que não existe. Foto de peça é sempre fotografia (R-IMG-01).
- **Móvel que só combina**: peça "de projeto" que some no sofá. A peça da More se sustenta sozinha numa sala.

Regra: referência vira memória, nunca cópia. Vale para o que inspira e para o que se evita.
