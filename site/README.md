# Site estático (mymore.netlify.app)

Bundle gerado por `/mnt/project-files/more/deploy.sh` (monta as pastas do projeto e aplica o shell de navegação de `nav/integrar.sh`).
Raiz = índice das páginas; `/guia/` (guia do time), `/sistema/` (este repositório), `/colecao/`, `/loja-3d/`, `/abertura/`.
`_redirects` mantém os endereços antigos (/resumo/, /mapa/, peças da abertura).

Publicação no Netlify: diretório base `site`, diretório de publicação `.`, sem comando de build (ver `netlify.toml`).
Não há segredos nem a senha do site neste bundle.
