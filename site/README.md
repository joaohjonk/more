# Site estático (mymore.netlify.app)

Bundle gerado por `/mnt/project-files/more/deploy.sh` a partir das pastas do projeto:
guia do time (raiz), `/sistema/` (este repositório), `/colecao/`, `/loja-3d/`, `/abertura/`, `/mapa/`.

Publicação no Netlify: diretório base `site`, diretório de publicação `.`, sem comando de build (ver `netlify.toml`).
Não há segredos nem a senha do site neste bundle; qualquer novo arquivo deve manter isso.
